# Google Maps Scraper & Leads Generator  

A Python-based Google Maps scraper that extracts business details from search queries. It takes a query like `"coffee shops in Boston"` and returns key details such as place name, contact information, ratings, and website.

## Features  
- Scrapes business details from Google Maps  
- Extracts:  
  - **Place Name**  
  - **Contact Information**  
  - **Ratings**  
  - **Website**  
- Saves results in a structured format (CSV, JSON, or database)
